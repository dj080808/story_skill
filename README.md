# 儿童故事生成 Skill

一个 Claude Code skill，根据用户指定的**动画角色**和**故事主题**，自动生成适合 3–8 岁儿童的原创短故事。

## 效果演示

```
输入：写一个喜羊羊春游的故事

输出：《喜羊羊和春天的陷阱》
      春天来了，羊村的小羊们去草原春游。灰太狼
      在路中间挖了一个大坑，盖上草皮和野花……
      （完整故事，300–500 字，角色性格一致，原作节奏还原）
```

## 如何添加新角色

新增一个动画角色需要改 **3 个文件**，大约 5 分钟：

### Step 1：创建角色文件

在 `references/characters/` 下新建一个 `.md` 文件，包含三个部分：

```markdown
# 动画名称

## 原作叙事模式          ← 最重要！这个动画每集的固定节奏是什么？
（节拍式描述）

## 主要角色
| 维度 | 内容 |
|------|------|
| **性格特点** | …… |
| **口头禅** | …… |
| **擅长的事** | …… |
| **不擅长的事** | …… |
| **主要人际关系** | …… |

## 故事中可用的配角      ← 列出其它角色，标注哪些是"必须出场"
```

参考已有文件（如 `xiyangyang.md`、`ultraman.md`）照着格式写即可。

### Step 2：注册到索引

编辑 `references/characters.md`，在**文件映射表**末尾加一行：

```markdown
| 新角色关键词、别名 | `references/characters/新文件名.md` |
```

同时在**快速主题匹配表**里更新相关主题的推荐角色排序。

### Step 3：注册到 SKILL.md 路由表

编辑 `SKILL.md`，在 Step 2 的路由表末尾加一行：

```markdown
| 新角色关键词 | `references/characters/新文件名.md` |
```

### Step 4：验证

用新角色发一个测试请求，检查：
- [ ] 角色文件被正确加载（LLM 读到了角色设定）
- [ ] 故事遵循了原作叙事模式
- [ ] 角色的口头禅和性格特点自然融入

---

示例：上次添加"迪迦奥特曼"只改了 3 个文件（`ultraman.md` + `characters.md` + `SKILL.md`），实际编写时间约 5 分钟。

## 适合的主题

分享、勇气、友谊、合作、环保、诚实、帮助他人、智慧、责任、不放弃、亲情、自信、接纳自己……

## 安装

1. 将 `.skill` 文件放到 Claude Code 的 skills 目录：

```
~/.claude/skills/children-story.skill
```

2. 或者将本项目文件夹放到 skills 目录：

```
~/.claude/skills/children-story-skill/
```

3. 重启 Claude Code，或使用 `/skills` 命令加载。

## 使用方式

在 Claude Code 对话中直接说：

```
"帮我写一个关于小猪佩奇学会分享的故事"
"用哆啦A梦写一个关于勇气的儿童故事"
"写一个汪汪队主题的环保故事"
"来个喜羊羊变大药丸的故事"
"用迪迦奥特曼写一个不放弃的睡前故事"
```

触发关键词：`儿童故事`、`睡前故事`、`给宝宝讲故事`、`写一个关于XX的故事`，或直接提及支持的角色名。

## 设计原则

- **角色驱动**：故事必须由角色的性格特点驱动，不做"换谁都行"的模板文
- **原作节奏**：每部动画都有独特的叙事模式（如喜羊羊必须有灰太狼出场、有"抓→逃"节奏）
- **不说教**：主题通过角色的行为和感受自然传递，不出现"这个故事告诉我们"
- **按需加载**：角色设定拆分为独立文件，生成故事时只读目标角色的文件，节省 token

## 质量基准

每篇生成的故事需满足：

- [x] 角色口头禅出现 ≥1 次
- [x] 角色性格推动情节（换一个角色讲不了）
- [x] 遵循该动画的原作叙事模式
- [x] 对话占比 40% 以上
- [x] 无说教句、无四字成语、每句 ≤20 字
- [x] 字数 300–500 字
- [x] 结尾有情感收束
