# 喜羊羊与灰太狼

## 原作叙事模式

```
场景：羊村 / 青青草原
起因：灰太狼为了给红太狼抓羊当晚餐，带着新发明/陷阱来羊村抓羊
经过：某只羊中招被抓 → 喜羊羊观察分析 → 找到狼的弱点/发明的漏洞
结局：羊群脱险 → 灰太狼狼狈飞走 → "我一定会回来的！"
```

> **味道关键词**：智斗、发明对战、抓与逃、喜羊羊的智慧、狼羊对抗。
> ⚠️ **灰太狼必须出场！** 没有狼的羊故事不是真正的喜羊羊故事。

---

## 喜羊羊（Pleasant Goat）

| 维度 | 内容 |
|------|------|
| **性格特点** | 聪明机智、乐观向上、勇敢但不鲁莽、善于随机应变 |
| **口头禅** | "有了！""看我的！" |
| **擅长的事** | 想办法对付灰太狼、发明小装置、带领羊村小伙伴脱险 |
| **不擅长的事** | 正面打架（更擅长智取）、拒绝朋友的请求 |
| **主要人际关系** | 美羊羊、懒羊羊、沸羊羊、慢羊羊村长、对手灰太狼 |

## 懒羊羊（Lazy Goat）

| 维度 | 内容 |
|------|------|
| **性格特点** | 贪吃贪睡、单纯可爱、运气好、关键时刻总能歪打正着 |
| **口头禅** | "我好饿啊……""再让我睡一会儿嘛！" |
| **擅长的事** | 吃东西、睡觉、在危机中莫名其妙脱险 |
| **不擅长的事** | 跑步锻炼、早起、做任何需要花力气的事 |
| **主要人际关系** | 喜羊羊（最好的朋友同时也是"保姆"）、美羊羊、沸羊羊 |

## 故事中可用的配角

- **灰太狼（Wolffy）** ⚠️ 必须出场：反派，爱搞发明、怕老婆、口头禅"我一定会回来的！"
- **红太狼**：灰太狼的妻子，用平底锅打灰太狼催他去抓羊
- **慢羊羊村长**：羊村长老，发明家，行动慢但智慧深
- **美羊羊**：爱美温柔的小母羊
- **沸羊羊**：力气大、性格直爽，擅长正面出击
- **暖羊羊**：善良暖心，体型大，常在关键时刻保护大家
