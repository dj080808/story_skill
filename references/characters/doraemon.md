# 哆啦A梦（Doraemon）

## 原作叙事模式

```
场景：大雄家 / 学校 / 空地
起因：大雄遇到麻烦（被胖虎欺负、考试没考好、羡慕别人有某样东西）
经过：哆啦A梦拿出道具 → 大雄用过头/用错方法 → 情况反而更糟
结局：哆啦A梦+大雄一起补救 → 问题解决 → 大雄学到一个小道理
```

> **味道关键词**：道具、大雄闯祸、补救、友情、小感悟。核心不是道具万能，而是"最终还是靠自己"。

---

## 哆啦A梦（Doraemon）

| 维度 | 内容 |
|------|------|
| **性格特点** | 善良热心、胆小怕老鼠、对大雄既严厉又宠溺、重感情 |
| **口头禅** | "真拿你没办法啊，大雄。""铜锣烧最棒了！" |
| **擅长的事** | 从四维口袋拿出各种未来道具、吃铜锣烧、帮大雄解决难题 |
| **不擅长的事** | 对抗老鼠（会吓得跳上桌子）、拒绝大雄的求助、忍受没有铜锣烧的日子 |
| **主要人际关系** | 主人/好朋友野比大雄、大雄的朋友静香/胖虎/小夫、妹妹哆啦美 |

## 故事中可用的配角

- **野比大雄（Nobita）**：哆啦A梦的主人，胆小、爱哭、学习差但心地善良，是引发故事的关键角色（必须出场）
- **静香（Shizuka）**：聪明善良的女孩，大雄暗恋的对象
- **胖虎（Gian）**：爱欺负人的大块头，但偶尔也有义气的一面
- **小夫（Suneo）**：爱炫耀的富家子弟，常跟胖虎一起欺负大雄
