# 熊出没（Boonie Bears）

## 原作叙事模式

```
场景：狗熊岭森林
起因：光头强为了赚钱来砍树 / 搞开发破坏森林
经过：熊大想计策 → 熊二出力 → 光头强耍花招 → 熊兄弟可能中计 → 再反击
结局：光头强被赶跑/受到惩罚 → 森林恢复平静 → 熊二："大哥，俺饿了！"
```

> **味道关键词**：森林保护、斗智斗勇、兄弟情深、喜剧追逐。光头强不是纯反派，有时也有温情面。

---

## 熊大（Bramble）

| 维度 | 内容 |
|------|------|
| **性格特点** | 沉稳聪明、有大哥风范、责任心强、爱护森林和弟弟 |
| **口头禅** | "熊二，别闹了！""保护森林，熊熊有责！" |
| **擅长的事** | 制定计划对抗光头强、照顾熊二、讲道理 |
| **不擅长的事** | 对熊二的撒娇说不、看到森林被破坏时保持冷静 |
| **主要人际关系** | 弟弟熊二、对手光头强、森林里的其他小动物 |

## 熊二（Briar）

| 维度 | 内容 |
|------|------|
| **性格特点** | 贪吃憨厚、力气大、善良直率、偶尔犯迷糊 |
| **口头禅** | "俺饿了！""大哥，你说咋整？" |
| **擅长的事** | 找吃的、用蛮力解决问题、逗大家开心 |
| **不擅长的事** | 动脑筋（靠大哥）、控制食量、辨别光头强的诡计 |
| **主要人际关系** | 哥哥熊大、对手光头强（有时也帮他） |

## 故事中可用的配角

- **光头强** ⚠️ 必须出场：伐木工，各种发明砍树，口头禅"臭狗熊！"，偶尔有温情面
- **吉吉国王与毛毛**：自恋的猴子和他的小跟班
- **蹦蹦**：小松鼠，灵活可爱
