# 超级飞侠（Super Wings）

## 原作叙事模式

```
场景：世界某个国家的特色地点
起因：小朋友有包裹需求 / 遇到困难需要帮助
经过：金宝派乐迪送货 → 乐迪飞到目的地 → 认识当地小朋友 → 出现问题乐迪自己解决不了 → 呼叫对应特长的队友
结局：队友赶到协力解决 → 乐迪准时送达 → 简短介绍当地文化小知识
```

> **味道关键词**：环球冒险、送货、各国文化、团队支援、准时送达。每个故事介绍一个国家/地区。

---

## 乐迪（Jett）

| 维度 | 内容 |
|------|------|
| **性格特点** | 热情阳光、乐于助人、偶尔有点冒失、永远准时送达 |
| **口头禅** | "超级飞侠，出发！""每时每刻，准时送达！" |
| **擅长的事** | 飞行送货、认识各国小朋友、用速度解决问题 |
| **不擅长的事** | 遇到太复杂的问题需要伙伴支援、独自应对需要重型装备的任务 |
| **主要人际关系** | 金宝（控制塔调度员）、多多/小爱/酷飞等超级飞侠队友、世界各地的小朋友 |

## 小爱（Dizzy）

| 维度 | 内容 |
|------|------|
| **性格特点** | 温柔细心、善良有爱心、偶尔胆小但关键时刻很勇敢 |
| **口头禅** | "小爱来了！""别担心，我来帮你。" |
| **擅长的事** | 救援任务、照顾小动物、用救援绳索和吊钩解决问题 |
| **不擅长的事** | 面对太激烈的场面、拒绝需要帮助的人 |
| **主要人际关系** | 乐迪（最好的搭档）、金宝、其他超级飞侠队友 |

## 故事中可用的配角

- **金宝（Jimbo）**：控制塔调度员，在塔台指挥，是任务发起者
- **多多（Donnie）**：工程专家，擅长修理和改造
- **酷飞（Jerome）**：特技飞行专家，有点爱耍帅
- **小青（Mira）**：潜水专家，擅长水下任务
