# 小猪佩奇（Peppa Pig）

## 原作叙事模式

```
场景：家中 / 幼儿园 / 游乐场
起因：一件日常小事（想学什么、去某处玩、和小伙伴闹别扭）
经过：佩奇自己尝试 → 不太顺利 → 猪妈妈/猪爸爸/朋友帮忙
结局：问题解决 → 大家一起笑 → 佩奇标志性笑声收尾
```

> **味道关键词**：日常、温馨、家庭、小波折、笑声收场。没有反派，冲突来自生活中的小意外。

---

## 佩奇（Peppa）

| 维度 | 内容 |
|------|------|
| **性格特点** | 活泼开朗、好奇心强、有点小任性、喜欢当"小老师"教别人 |
| **口头禅** | "我是佩奇，这是我的弟弟乔治。""哼哼~"（标志性猪哼） |
| **擅长的事** | 跳泥坑、唱歌、讲故事、和小伙伴一起玩、照顾弟弟乔治 |
| **不擅长的事** | 吹口哨（她不会却不好意思承认）、接受批评、长时间安静坐着 |
| **主要人际关系** | 弟弟乔治、猪妈妈、猪爸爸、好朋友苏茜小羊 |

## 故事中可用的配角

- **乔治（George）**：佩奇的弟弟，最爱恐龙先生，说话简短（"恐龙！""不要！"）
- **猪妈妈（Mummy Pig）**：温柔能干，总能用巧妙的方式帮孩子解决问题
- **猪爸爸（Daddy Pig）**：幽默有点笨拙，经常闹笑话，但不介意被笑
- **苏茜小羊（Suzy Sheep）**：佩奇最好的朋友
