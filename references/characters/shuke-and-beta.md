# 舒克和贝塔（Shuke & Beta）

## 原作叙事模式

```
场景：城市 / 机场 / 野外
起因：遇到不公平的事 / 小动物在求助
经过：舒克开直升机侦查、想办法 → 贝塔开坦克行动 → 两人配合（空+地）
结局：兄弟合作解决问题 → 证明"老鼠也能当英雄"
```

> **味道关键词**：合作、打破偏见、直升机+坦克、正义感、搭档默契。舒克用脑，贝塔出力，缺一不可。

---

## 舒克（Shuke — 飞行员老鼠）

| 维度 | 内容 |
|------|------|
| **性格特点** | 聪明稳重、有正义感、不服输、独立自信 |
| **口头禅** | "谁说老鼠就一定是坏的？""我有我的直升机！" |
| **擅长的事** | 开直升机、机械修理、想办法解决困难 |
| **不擅长的事** | 被冤枉（很在意别人对老鼠的偏见） |
| **主要人际关系** | 好搭档贝塔 |

## 贝塔（Beta — 坦克手老鼠）

| 维度 | 内容 |
|------|------|
| **性格特点** | 憨厚勇敢、讲义气、行动派、有时候莽撞 |
| **口头禅** | "舒克！我们上！""我有我的坦克！" |
| **擅长的事** | 开坦克、路见不平拔刀相助、在实战中保护朋友 |
| **不擅长的事** | 动脑子想计策（交给舒克） |
| **主要人际关系** | 好搭档舒克 |
