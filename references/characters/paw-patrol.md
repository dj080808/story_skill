# 汪汪队立大功（PAW Patrol）

## 原作叙事模式

```
场景：冒险湾某处
起因：有人/动物遇到困难（被困、迷路、灾害、事故）
经过：莱德收到警报 → 分析任务、选择合适的狗狗队员 → 每只狗用自己的装备特长执行子任务
结局：团队合作解决问题 → "没有困难的工作，只有勇敢的狗狗！"
```

> **味道关键词**：救援、团队分工、装备、勇敢、口号收尾。每个队员各司其职，缺一不可。

---

## 莱德（Ryder）

| 维度 | 内容 |
|------|------|
| **性格特点** | 聪明冷静、领导力强、勇敢果断、关心每一只狗狗队员 |
| **口头禅** | "别担心，我来想办法！""汪汪队，集合！" |
| **擅长的事** | 分析问题、指挥救援任务、操作高科技装备、鼓励队员 |
| **不擅长的事** | 在需要分头行动时一个人做所有事、对需要帮助的人视而不见 |
| **主要人际关系** | 阿奇、毛毛、天天、小砾等所有汪汪队狗狗成员 |

## 阿奇（Chase）

| 维度 | 内容 |
|------|------|
| **性格特点** | 纪律性强、认真负责、偶尔过于严肃、对"特工/警察"身份非常自豪 |
| **口头禅** | "阿奇报到！""包在我身上！" |
| **擅长的事** | 追踪线索、指挥交通、使用警车装备、用扩音器喊话 |
| **不擅长的事** | 对羽毛和猫咪过敏（会打喷嚏）、开玩笑（容易当真）、处理太混乱的场面 |
| **主要人际关系** | 队长莱德、好朋友毛毛（经常搭警车一起出任务） |

## 故事中可用的配角

- **毛毛（Marshall）**：消防犬，呆萌笨拙、经常摔跤，但救火时非常勇敢
- **天天（Skye）**：飞行犬，粉色直升机，乐观爱美，擅长空中侦察
- **小砾（Rubble）**：工程犬，开推土机，力气大，喜欢各种食物
- **路马（Zuma）**：水上救生犬，开气垫船，性格悠闲
