# 迪迦奥特曼（Ultraman Tiga）

## 原作叙事模式

```
场景：地球城市 / TPC 基地
起因：怪兽出现，破坏城市，人类陷入危险
经过：胜利队出击对抗怪兽 → 普通武器无效 → 大古举起神光棒 → 变身迪迦
      → 迪迦与怪兽格斗 → 红灯开始闪烁（能量只剩一分钟）
      → 迪迦切换形态（力量型/速度型）应对怪兽弱点
结局：迪迦使出必杀技（哉佩利敖光线）击败怪兽 → 飞向天空 → 城市恢复和平
```

> **味道关键词**：变身、巨大化、红灯倒计时、形态切换、必杀技光线。
> 核心不是"奥特曼无敌"，而是"人类（大古）的勇气召唤了光"。

---

## 迪迦奥特曼（Ultraman Tiga）

| 维度 | 内容 |
|------|------|
| **性格特点** | 沉着冷静、有强烈的正义感与保护欲、战斗时观察力极强、对人类充满信任 |
| **口头禅** | "我不能放弃！""光是不会消失的。" |
| **擅长的事** | 格斗、切换三种形态应对不同敌人、把握战机使出必杀技 |
| **不擅长的事** | 活动时间只有三分钟（红灯闪烁后力量减弱）、水下/宇宙等特殊环境受限 |
| **主要人际关系** | 人间体真角大古、胜利队队友（丽娜、队长居间惠、新城、堀井、野瑞） |

## 变身机制（写故事时必须遵守）

- **人间体**：真角大古（Daigo），胜利队队员，用神光棒（Spark Lens）变身
- **红灯**：迪迦胸口彩色计时器从蓝色变红并闪烁时，表示能量不足，只剩约一分钟
- **三种形态**：

| 形态 | 颜色 | 特点 |
|------|------|------|
| 复合型 | 紫+红 | 均衡型，必杀技：哉佩利敖光线 |
| 力量型 | 红色 | 力量大但速度慢，适合对付重甲怪兽 |
| 空中型 | 紫色 | 速度快但力量弱，适合对付飞行怪兽 |

## 故事中可用的配角

- **真角大古（Daigo）**：迪迦的人间体，胜利队队员，勇敢善良，关键时刻总会挺身而出
- **丽娜（Rena）**：胜利队女飞行员，大古的搭档与恋人，驾驶飞燕一号
- **居间惠队长（Captain Iruma）**：胜利队队长，冷静睿智，某种程度上知道大古就是迪迦
- **新城（Shinjo）**：胜利队王牌飞行员，性格热血冲动
- **堀井（Horii）**：胜利队技术专家，发明各种装备
- **野瑞（Nozomu）**：TPC 基地天才电脑少年

## 适合主题

| 主题 | 说明 |
|------|------|
| 勇气 | 大古虽然害怕，仍然举起神光棒变身——核心主题 |
| 保护 | 迪迦保护地球和人类，不求回报 |
| 不放弃 | 红灯闪烁时反而是迪迦最强的时刻 |
| 团队 | 胜利队配合作战，迪迦不是孤身一人 |
| 相信光 | 人类的希望和勇气变成光的力量 |
