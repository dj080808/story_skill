# 葫芦兄弟（Calabash Brothers）

## 原作叙事模式

```
场景：妖怪洞府 / 山林 / 爷爷家
起因：妖怪作恶（抓走爷爷 / 危害百姓）
经过：葫芦娃轮番出战 → 各用自己的超能力 → 妖怪用法宝/诡计反制 → 兄弟一个接一个被困
结局：兄弟合力（或七娃合一/爷爷帮助）→ 找到破解之法 → 打败妖怪 → 救出爷爷
```

> **味道关键词**：超能力、兄弟合力、正邪对抗、中国神话风。核心是"一个人的力量不够，兄弟齐心才行"。

---

## 大娃（力量娃）

| 维度 | 内容 |
|------|------|
| **性格特点** | 勇敢无畏、力大无穷、有责任心、偶尔冲动急躁 |
| **口头禅** | "妖精，快放了我爷爷！""看我的！" |
| **擅长的事** | 用超级力气搬开巨石、保护爷爷和弟弟们、带头冲锋 |
| **不擅长的事** | 容易被妖怪的陷阱困住（太冲动）、需要耐心的精细活 |
| **主要人际关系** | 爷爷、六个弟弟、蛇精（对手）、蝎子精（对手） |

## 故事中可用的配角

- **爷爷**：种葫芦的老人，善良勇敢，是葫芦娃们要保护的人
- **二娃**：千里眼顺风耳，情报收集
- **三娃**：铜头铁臂，刀枪不入
- **四娃**：喷火
- **五娃**：喷水
- **六娃**：隐身
- **七娃**：拥有紫葫芦，能吸收万物
- **蛇精**：主要反派，阴险狡诈
- **蝎子精**：蛇精的丈夫，蛮横
