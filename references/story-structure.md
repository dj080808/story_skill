# 儿童故事结构指南

> 适用于 3–8 岁儿童的故事创作。本指南定义了故事结构、语言风格、角色融入和主题传递的规范，供 SKILL.md 引用。

---

## 一、目标读者

| 维度 | 说明 |
|------|------|
| **年龄段** | 3–8 岁（学龄前至小学低年级） |
| **注意力时长** | 约 3–5 分钟（听故事场景） |
| **词汇量** | 日常基础词汇为主，避免成语、抽象概念、复杂比喻 |
| **阅读场景** | 以家长朗读为主（听故事），辅以自主阅读（大龄段） |

---

## 二、故事结构：三段式（起因 → 经过 → 结局）

### 2.1 起因（开头，约占 20%）

**目的**：快速建立情境，让小朋友知道"谁、在哪、发生了什么事"。

**要点**：
- 第一句就点名主角和场景（例如："佩奇今天特别想吹口哨。"）
- 用一个具体的"小问题"或"小愿望"启动故事
- 起因要贴近儿童生活经验（想要某样东西、和朋友闹别扭、不敢做某事）

**常见起因类型**：

| 类型 | 示例 |
|------|------|
| 愿望型 | 乐迪收到了一个来自中国小朋友的包裹请求 |
| 困难型 | 熊二饿了，但蜂蜜罐卡在树上了 |
| 矛盾型 | 喜羊羊和懒羊羊因为一块蛋糕吵架了 |
| 好奇型 | 佩奇想知道彩虹的尽头有什么 |
| 恐惧型 | 小爱不敢独自穿过黑黑的隧道去救小猫 |

### 2.2 经过（发展，约占 60%）

**目的**：展开解决问题的过程，这是故事的主体。

**要点**：
- **三步节奏**：尝试 → 遇挫 → 再尝试。一般安排 2–3 次尝试，让故事有起伏
- **重复句式**：每次尝试用类似的句式开头，形成节奏感和可预测性（儿童喜欢重复）
- **角色特点驱动**：解决方案要体现角色的"擅长"和"不擅长"，让情节和人物绑定
- **帮手出现**：可以在第二次尝试时引入朋友/家人的帮助，传递合作价值

**经典经过骨架**：
1. **第一次尝试** → 失败了（因为角色的某个弱点/不擅长的事）
2. **第二次尝试** → 受到启发或得到帮助（人际关系发挥作用）
3. **第三次尝试** → 调整方法，接近成功

> 不是所有故事都要三次尝试；300 字故事用 2 次即可，500 字故事可用 3 次。

### 2.3 结局（收尾，约占 20%）

**目的**：问题解决 + 情感收束 + 主题自然浮现。

**要点**：
- 问题圆满解决（儿童故事需要安全感，避免开放式结局）
- 用一句简单的话点出感受，不要说"这个故事告诉我们……"
- 可以回到开头场景形成闭环（"佩奇终于学会了吹口哨，她开心地哼了一声"）

**好结局 vs 说教结局**：

| ❌ 说教式 | ✅ 自然式 |
|----------|----------|
| "所以我们要学会分享。" | "佩奇把蛋糕分给苏茜，两个人笑着一起吃——这块蛋糕好像比刚才更甜了！" |
| "这个故事告诉我们勇敢很重要。" | "小爱深吸一口气，飞进了隧道。等她出来时，怀里抱着小猫——她才发现，隧道其实没那么黑。" |

## 三、语言风格规范

### 3.1 词汇要求

| 原则 | 说明 |
|------|------|
| **用具体词，不用抽象词** | "开心"优于"幸福"，"大哭"优于"悲伤"，"黑黑的"优于"黑暗" |
| **多用叠词和拟声词** | 慢慢走、咚咚响、哗啦啦、咕噜咕噜、哼哼 |
| **避免成语** | "齐心协力"→ "大家一起帮忙" |
| **人名+动作开头** | 以角色名开头让孩子知道"谁在做"： "佩奇跳进泥坑里。" 优于 "泥坑被佩奇跳进去了。" |

### 3.2 句式要求

| 原则 | 说明 |
|------|------|
| **短句为主** | 每句 8–15 字，最多不超过 20 字 |
| **口语化** | 用"可是""然后""哇"这类日常连接词，不用"然而""因此""从而" |
| **重复节奏** | 关键句在故事中重复 2–3 次（如"没有困难的工作，只有勇敢的狗狗"） |
| **对话丰富** | 对话占比约 40–50%，让角色"说话"而不是叙述者"转述" |
| **感叹句+问句** | 穿插"哇！""咦？""怎么办呢？"增加互动感 |

### 3.3 节奏模式示例

```
[动作] → [对话] → [小结果] → [新动作] → [对话] → [大结果]
```

连载式例子：
> 佩奇鼓起腮帮子，"呼——"没有声音。
> 她又试了一次，"呼——呼——"还是没有声音。
> "怎么办呢？"佩奇歪着脑袋。
> 这时猪爸爸走过来，"佩奇，试试这样……"
> 佩奇照着做，"呼——"一声轻轻的口哨响了起来！
> "我成功了！"佩奇高兴地跳了起来。

### 3.4 禁止用语

- ❌ 说教词："应该""必须""要懂得""大家都来学学"
- ❌ 恐吓词："不然就会有危险""否则大灰狼会来"
- ❌ 负面标签："你真笨""太没用了"
- ❌ 成人化表达："反思""成长""价值观"

## 四、角色特点的自然融入

### 4.1 原则：用行为说话，不用标签说话

不写"阿奇很认真"，而是写阿奇在行动中表现出认真：
> 阿奇把每颗纽扣都整整齐齐地检查了一遍，确认没有一颗是松的。

### 4.2 融入技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **口头禅开场** | 角色登场时用口头禅自然亮相 | 乐迪："每时每刻，准时送达！咦，这次的包裹好特别呀——" |
| **弱点制造冲突** | 用"不擅长的事"设计挫折点 | 哆啦A梦最怕老鼠，偏偏这次要救的是一只小老鼠 |
| **特长解决问题** | 用"擅长的事"设计转折点 | 熊大冷静观察，想出了一个引诱光头强离开的计划 |
| **人际关系推进剧情** | 让朋友/家人出现推动第二步尝试 | 佩奇自己搞不定，去找苏茜帮忙一起想办法 |
| **口头禅收尾** | 结尾用口头禅呼应，形成圆满感 | "汪汪队，又一次完成了任务！" |

### 4.3 融入检查清单

生成故事后自查：
- [ ] 角色的口头禅至少出现 1 次
- [ ] 角色的"擅长"在故事中派上了用场
- [ ] 角色的"不擅长"制造了合理的困难
- [ ] 角色的人际关系在故事中有体现
- [ ] 换一个角色还能讲这个故事吗？（如果能，说明角色特点融入不够深）

## 五、正向主题的自然传递

### 5.1 核心原则：让读者自己"感受到"，而不是"被告诉"

**方法**：把主题藏在角色的选择和结果里。

| 主题 | 不说教 | 而是…… |
|------|--------|---------|
| 分享 | "要懂得分享。" | 角色分享了某样东西后，发现大家一起享受比一个人独享更快乐。 |
| 勇气 | "要勇敢。" | 角色虽然很害怕，但还是迈出了一步，然后发现没那么可怕。 |
| 合作 | "团结力量大。" | 两个角色各自解决不了问题，一起合作就做到了，他们开心地击掌。 |
| 诚实 | "不要说谎。" | 角色说了实话后得到了拥抱和理解，而不是惩罚。 |
| 环保 | "要保护环境。" | 角色看到被污染的小河让小动物无家可归，于是动手清理，小动物们回来了。 |

### 5.2 主题传递技巧

1. **对比法**：展示"做之前"和"做之后"的变化，让小朋友自己感受哪个更好
2. **角色感受法**：聚焦角色的情绪变化——从困惑/害怕到开心/安心
3. **自然结果法**：让好的行为带来好的自然结果（不是外部奖励），坏的行为带来不舒服的体验（不是惩罚）
4. **一句话收尾法**：结尾用角色的一句话点出感受，如"原来和大家一起玩，比自己一个人玩有意思多了！"

## 六、字数控制

| 故事部分 | 占比 | 300 字故事 | 500 字故事 |
|----------|------|-----------|-----------|
| 起因 | 20% | ~60 字 | ~100 字 |
| 经过 | 60% | ~180 字 | ~300 字 |
| 结局 | 20% | ~60 字 | ~100 字 |

**建议**：默认生成 400 字左右的故事。用户指定"短一点"时走 300 字档，"长一点"时走 500 字档。

---

## 七、故事质量快速自查

生成故事后，按以下清单检查：

- [ ] 第一句就出现了主角和场景
- [ ] 起因是一个具体的"小问题/小愿望"
- [ ] 经过有波折（至少一次失败或困难）
- [ ] 解决了，不是被外部力量"碰巧"解决的
- [ ] 角色的口头禅至少出现 1 次
- [ ] 角色的性格特点驱动了情节（不是角色被情节拖着走）
- [ ] 对话占比 40% 以上
- [ ] 没有说教句（"这个故事告诉我们""我们要""应该"）
- [ ] 没有四字成语
- [ ] 每句话不超过 20 字
- [ ] 台词中有感叹和疑问（"哇！""咦？""怎么办？"）
- [ ] 字数在 300–500 字之间
- [ ] 结尾有情感收束，不是戛然而止
